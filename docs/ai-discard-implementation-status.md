# AI 出牌逻辑实施状态

本文档按 `docs/ai-discard-logic-spec.md` 记录当前实现证据和剩余验收，不替代原始 spec。

玩家点击、分析、弃牌和选择状态的实施证据单独记录在 `docs/ai-interaction-implementation-status.md`，不得用本文档的 P0-P4 状态替代交互一致性验收。

## P0：统一实际运行路径

状态：实现完成，静态与 HTTP 验证完成。

- 普通对局唯一入口为 HTML 内的 `aiChooseDiscard` 和 `aiRespond`。
- `AI_ENGINE_INFO` 输出引擎 ID、版本、模式和来源，当前版本为 `2026-06-20-p0-p4-r2`。
- `markAiEntrypoints` 和 `auditAiEntrypoints` 检查入口是否被覆盖，并写入每局日志。
- 普通对局 MCTS/RL 默认关闭；游戏内设置可显式开启，自弈模式与普通模式分别配置。
- MCTS/RL 候选只有综合向听不劣于规则基线时才允许覆盖。

## P1：修复明显低级策略问题

状态：实现与运行时牌例回归完成。

- 孤张平手选择使用最低连接度。
- 同向听候选保护完整面子、对子、两面/嵌张搭子。
- 假搭子使用自己手牌与公开信息计算，不读取其他玩家暗手。
- 听牌弃牌同时比较等张种类、剩余枚数和安全分。
- AI 摸牌后自摸优先于自杠。
- 明杠、暗杠和加杠同时检查综合向听与杠前/杠后待牌集合；丢失原待牌时跳过。
- 碰牌按碰后所有合法弃牌中的最佳综合向听评估。
- 已有副露时，向听评估计入固定面子并禁用七对、打烂、半正宗、全正宗闭门路线。

## P2：增加 AI 决策解释

状态：实现与浏览器交互验收完成。

- `ai-decision-v1` 记录玩家、阶段、手牌、弃牌、来源、路线、出牌前后向听、候选、原因和防守信息。
- 候选记录结构破坏、等张种类、剩余枚数、安全分、路线分和综合分。
- 响应日志覆盖自摸、胡、碰、杠、跳过杠和过牌。
- 杠牌响应记录 `waitBefore`、`waitAfter` 和 `lostWaits`；碰牌记录 `bestDiscard`。
- AI 日志面板展示最近决策，导出使用 `ai-decision-export-v1`；对局结束后可读取最近保存记录。
- 稳定字段定义见 `docs/ai-log-schema.md`。

## P3：建立标准牌例集

状态：牌例数据与 20 例浏览器运行时回归完成。

- `docs/ai-standard-cases.md` 和 `docs/ai-standard-cases.json` 包含 20 个唯一牌例。
- 每个牌例包含手牌、局面、期望和关注点。
- `case-17` 使用可复现暗杠牌形：杠前听 `wan6/wan8/wan9`，杠后只听 `wan8`，期望 `skipSelfKong`。
- JSON 已验证可解析、数量为 20、ID 唯一且必要字段完整。
- 20 个牌例已在隔离浏览器中使用实际页面函数逐项执行，结果为 `20/20`。

## P4：优化防守模型

状态：启发式模型实现完成，标准防守局面运行时验收完成。

- 威胁模型包含对手听牌估算、副露、牌河长度、末盘和近期弃牌特征。
- 安全模型包含逐个对手现物、筋牌、壁牌、副露花色危险和多个高威胁对手惩罚。
- 分数领先提高防守权重；落后且接近听牌时设置 `attackTolerance: true` 并降低防守权重。
- `fullFold` 从全部手牌中选安全牌，允许为安全牺牲向听；其他模式仍优先进攻效率。

## 本轮回归修复

- 修复结构二次过滤使用旧索引导致 `subHands` 变为 `undefined` 的运行时异常。
- 特殊路线同向听时按 `全正宗 > 半正宗 > 打烂` 归类。
- 半正宗规则改为每个花色内部单组、不同花色可跨组，避免覆盖所有打烂牌形。
- 听牌质量比较前移，最大进张不再被通用结构过滤提前删除。
- 拟弃牌计入已见牌，零枚待牌不再计入 `waitCount`。
- 高危险 `semiFold` 在同向听候选中优先安全牌。
