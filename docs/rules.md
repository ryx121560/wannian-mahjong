# 万年麻将完整规则文档

本文档描述当前阶段一规则引擎可验证、可运行的规则边界。规则真源位于 `src/game/rules`，浏览器运行时通过 `public/game/rule_engine.js` 加载同一份规则引擎。

## 基础规则

- 四人麻将：1 名真人玩家和 3 名 AI。
- 使用 136 张牌：万、筒、条各 1-9，每种 4 张；字牌为东、南、西、北、中、发、白，每种 4 张。
- 当前规则不支持吃牌。
- 支持碰、明杠、暗杠、加杠、直铲、连杠、过水、自摸、点炮、抢杠、杠开、天地胡等规则边界。
- 规则引擎函数接收普通数据结构并返回普通数据结构，不操作 DOM，不依赖浏览器 API。

## 运行时接入

- Node.js 评测入口：`scripts/benchmark-runner.mjs`。
- 浏览器规则包构建入口：`scripts/build-browser-rule-engine.mjs`。
- 浏览器全局入口：`window.WannianRuleEngine`。
- HTML 对局运行时已委托规则引擎处理胡牌判定、牌型展示、胡牌计分、碰/杠合法性。
- HTML 对局运行时已委托规则引擎处理 AI 向听路线。
- HTML 中 AI 候选排序、防守评分和日志复盘仍是 AI 决策层逻辑，不作为规则判定真源。

## 牌型路线

### 标准胡牌

标准胡牌按 4 组面子加 1 组将头判定。面子包括同花色顺子、刻子，以及万年麻将规则下的特殊字牌组合。

### 字牌特殊组合

- 东、南、西、北中任意三张不同风牌可按一组面子处理。
- 中、发、白三张不同箭牌可按一组面子处理。

### 七对

七对按 7 组对子判定，不允许带副露。

### 全风向

全风向要求手牌全部为字牌。当前作为高优先级特殊牌型，基础分 16，并参与封顶。

### 打烂体系

打烂要求 14 张全不同、至少 5 种字牌，并且同花色内数值间距不小于 3。

打烂子型包括：

- 打烂：满足基础打烂条件。
- 半正宗：每个花色内部只使用 `147`、`258` 或 `369` 中的一组，不同花色可使用不同组。
- 全正宗：所有花色统一使用同一组 `147`、`258` 或 `369`。
- 七字半正宗：七种字牌齐全，同时满足半正宗。
- 七字全正宗：七种字牌齐全，同时满足全正宗。

## 牌型叠加

`classifyHand` 返回所有命中的牌型，并计算叠加后的 `baseScore`。当前可验证的叠加包括：

- 清一色 + 碰碰胡
- 混一色 + 碰碰胡
- 清一色 + 七对

主牌型 `primaryType` 取基础分最高的命中牌型，用于兼容现有结算展示；完整叠加信息通过 `handTypes` 和 `baseScore` 提供。

## 计分规则

- 平胡、打烂：基础分 1。
- 七对、碰碰胡、混一色、半正宗：基础分 2。
- 清一色、全正宗、七字半正宗：基础分 4。
- 七字全正宗：基础分 8。
- 全风向：基础分 16。
- 点炮按单一放炮方结算。
- 自摸、杠开、天地胡按三家支付结算。
- 抢杠由被抢杠玩家支付。
- 单家封顶为 16 分。
- `calculateScore` 支持牌型叠加、杠开、没走色、真假胡、连杠、直铲和封顶计算。

## 杠类与直铲

- `canPeng` 判断碰牌合法性。
- `canAnGang` 判断手中四张相同牌的暗杠。
- `canMingGang` 判断已有碰牌后摸到同牌的加杠。
- `canQiangXingPaoGang` 判断强行跑杠。
- `canZhiChan` 判断听牌状态下的直铲。
- `canLianGang` 判断杠后补牌是否可继续连杠。
- `getGangDrawTile` 从牌墙尾部取杠后补牌。

## 宝牌与真假胡

`resolveWildcard` 先判断原始牌是否已经真胡；如果不能真胡，会尝试用所有牌替换宝牌并判断是否可胡。当前 L1 用例覆盖真胡和假胡基础路径。

## 过水规则

同一玩家在同一轮对同一张牌选择过后，本轮再次遇到同一张牌不能胡；新轮次不沿用上一轮过水记录。

## 听牌与向听

- `checkTenpai` 枚举可胡牌并返回剩余张数、胡牌后牌型和基础分。
- `getShanten` 返回标准胡、七对、打烂、半正宗、全正宗的阶段一近似向听，并给出推荐路线。

## 合法动作

`getLegalActions` 根据当前阶段返回可执行动作：

- 出牌阶段：`discard`、`selfWin`、`concealedKong`、`addedKong`。
- 响应阶段：`win`、`pong`、`openKong`、`pass`。

## 自动化评测

标准牌例位于 `docs/rule-standard-cases.json`，当前包含 451 条 L1 用例。

评测命令：

```powershell
npm.cmd run verify:browser-rules
npm.cmd run test:rules -- --level L1
npm.cmd run test:rules -- --category dalan
npm.cmd run test:rules -- --report json
npm.cmd run build
```

验收结果要求为 L1 100% 通过。当前已验证 451/451 通过。

## 已知边界

- `getShanten` 是阶段一基础评测函数，不等同于完整强 AI 评分模型。
- AI 候选排序和防守评分仍包含历史启发式逻辑；规则判定真源以 `src/game/rules` 为准。
- 新发现的真实牌局问题必须先补入标准用例或生成器，再修改规则实现。
