# P1 顶部唯一积分栏纠正验收报告

状态：产品验收通过，已集成待推送；未部署。

## 目标

顶部 `#bar` 是页面唯一、固定顶部居中的四家当前积分栏。短 `#scorebar` 保持删除，状态与结算文本不得覆盖积分。

## 改动

- `#bar` 显式使用 `box-sizing:border-box`，桌面和小屏外框均包含 padding、边框且不超出视口。
- `updateTopScoreBar()` 优先使用真实玩家席位名；无玩家或游戏状态缺失时，稳定回退为你、AI 下家、AI 对家、AI 上家。
- `setMsg()` 只保存内部状态并刷新积分，回合、弃牌、响应、结算和自弈文本不再进入视觉顶部栏。
- idle、新局、刷新恢复、普通胡、流局、杠开、破产重置及自弈均通过同一积分渲染点更新；自弈面板没有第二处四家积分。
