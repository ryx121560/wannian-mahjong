### 为什么顺序重要（实测事实）

`main` 与候选的页面文件**不是同一世代**：

| | `main` 工作区 | 候选工作树 |
|---|---|---|
| 文件 | `public/game/wannian-mahjong.html` | 同左 |
| 大小 | **235,988 B** | **304,873 B** |
| 最后修改 | **2026-08-21 20:15** | 2026-09-24 15:03 |
| `#bar` | `<div id="bar">点击「新游戏」开始</div>` | `<div id="bar" aria-live="polite">当前积分加载中</div>` |
| `#scorebar` | **存在**（`<div id="scorebar" aria-live="polite">`） | **已移除** |
| `_statusMessage` | 0 处 | 4 处 |
| `updateTopScoreBar` | 0 处 | 1 处 |

即：`main` 目前是**双栏结构**（`#bar` 提示 + `#scorebar` 积分），候选是**统一 `#bar`**。

**若在候选合入前直接改 `main` 的 `#suggest`，该修改会在候选合入时变成新的冲突**，
且同一修复逻辑要针对两套结构各写一遍。这是选择 A 必须接受的约束。
