# 万年麻将项目目标

## 目标

把桌面上的万年麻将 Next.js 项目整理成一个可维护的项目结构，先保留现有玩法可运行，再逐步把静态 HTML 中的游戏逻辑迁移到 TypeScript 模块。

## 第一版范围

- 保留 Next.js App Router。
- 保留 `public/game/wannian-mahjong.html` 作为当前游戏入口。
- 页面入口、业务页面、展示组件、游戏工具、类型定义分层放置。
- 不引入新依赖。
- 不重写完整麻将规则。

## 暂缓事项

- 联网对战。
- 账号系统。
- 数据库持久化。
- 完整 React 组件化麻将桌。
- 完整 AI 重写。
